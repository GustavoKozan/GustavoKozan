<details>
<summary>🐍 Setup Snake Animation</summary>

<br>

Para ativar a **Snake Contribution Animation**, crie o arquivo `.github/workflows/snake.yml` no seu repositório com o conteúdo abaixo:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:

permissions:
  contents: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Generate Snake Game
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: GustavoKozan
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
          publish_branch: output
```

Após criar o workflow, execute-o manualmente pelo tab **Actions** do seu repositório.  
A animação será gerada e ficará disponível na branch `output`.

</details>
